# ADR-002：数据源合规边界

- 状态：Accepted（2026-08-03，待产品/法务/安全负责人最终评审确认）
- 日期：2026-08-03
- 决策人：项目技术负责人

## 背景

系统依赖数据采集；采集合法性是可持续运营的前提（技术方案前置条件 EXT-001）。

## 决策

### 允许的接入方式

1. 官方/合作方提供的 API（含书面授权）。
2. 用户明确授权的公开数据接口。
3. 已授权数据源的浏览器采集（Playwright，见 ADR-005）——仅读取用户授权范围内的公开商品信息。

### 明确禁止（任何情况下）

- 验证码绕过、风控绕过、指纹伪装、UA/代理池轮换。
- 账号池、批量注册、登录态共享/买卖。
- 签名逆向、接口逆向绕过授权。
- 自动下单、抢拍、批量强聊。
- 采集非授权范围的个人信息（卖家/买家隐私字段仅保留脱敏哈希）。

### 会话与凭据管理

- 真实账号凭据与授权 `storageState` 必须进入**受控密钥存储**（`runtime/`，已被 `.gitignore` 排除），禁止提交 Git。
- 采集频率、并发数、重试次数与会话数量由调度器/配额服务统一控制（COL-003 的锁与配额）。
- 任何真实数据源凭据的启用需经过数据源授权评审（EXT-001）。

### 数据边界

- 商品事件只输出 `RawProductEvent`（含 `seller_id_hash` 脱敏、`raw_payload` 受限访问）。
- 采集适配器不得直接写业务数据库、做价格判断或发送通知。

## 落地检查

- `packages/datasource-sdk/src/adapter.ts`：适配器接口只输出 RawProductEvent。
- `docs/adr/ADR-005-playwright-collector.md`：Playwright 使用约束。
- `.gitignore`：`runtime/`、`*.storage-state.json`、密钥类文件排除。
- `docs/open-source/xianyu-open-source-evaluation.md`：不复制高风险实现。
